# Recursos pendientes del hero

La interfaz está preparada para cargar estos archivos sin cambiar el diseño:

- `canam-maverick-x3-hero.webp`: fotografía horizontal real o con licencia, mínimo 1920 × 1080, sin texto incorporado. Debe mostrar un Can-Am Maverick X3 reconocible y un solo vehículo.
- `jalip-motorsport-logo.png`: logotipo oficial transparente de Jalip Motorsport, con contraste suficiente para fondo oscuro.

No se debe sustituir ninguno por una recreación tipográfica, un logotipo generado o un UTV genérico.
